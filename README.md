## Что умеет AssistVoice

Настраиваете свои голосовые команды — и часы (или телефон) реагируют на них мгновенно, без интернета и без задержек на распознавание в облаке.

- 🎙 **Полностью офлайн** — ни слово из того, что вы говорите, никуда не отправляется.
- 📱 **Запуск приложений голосом** — заранее настройте в приложении, какое слово открывает какое приложение, и дальше просто произносите его.
- 📞 **Звонки голосом** — то же самое для звонков: настраиваете слово-команду для контакта, дальше звоните голосом.
- ☎️ **Ответ на звонок без рук** — «прими звонок» / «отклони звонок» работают прямо во время входящего вызова, ничего заранее настраивать не нужно.
- 🔦 **Экранный фонарик** — «включи фонарик» / «выключи фонарик».
- 🎵 **Управление музыкой голосом** — плеер на устройстве слушается голосовых команд.
- ✨ **VIP: свободный звонок по имени** — можно позвонить любому контакту из телефонной книги голосом, без предварительной настройки каждого контакта отдельно.
- ✨ **VIP: Умный дом Яндекса** — включайте и выключайте устройства и группы устройств голосом.
- 🔋 **Бережно к батарее** — слушает только тогда, когда действительно нужно.

AssistVoice полностью бесплатен. VIP-статус, который открывает VIP-возможности выше, даётся просто за подписку на [Telegram-канал автора](https://t.me/bynikolay) — без каких-либо платежей.

## Установка

1. Откройте вкладку **[Releases](https://github.com/feed4me/Assist-Voice/releases/latest)** и скачайте последний `.apk`.
2. Установите файл на часы или телефон.
3. Откройте AssistVoice и разрешите то, что он попросит — микрофон, контакты, телефон и т. д. — или выдайте необходимые разрешения самостоятельно.
4. Включите AssistVoice в системных настройках специальных возможностей (это необходимо, чтобы приложение могло слушать команды в фоне) — приложение подскажет, куда зайти.
5. На вкладке «Команды» настройте свои голосовые команды.

### Обновление

В AssistVoice встроено самообновление: на стартовой странице приложения нажмите «Проверить обновления» — если вышла новая версия, приложение скачает и установит её само.
