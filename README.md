Assist Voice выполняет голосовые команды, которые вы настроили сами: открывает приложения и их экраны, звонит, делает скриншот и другие системные действия, ставит таймер, управляет музыкой. С интеграциями — включает свет в Умном доме Яндекса, открывает калитку и показывает камеры Hikvision, заводит машину через StarLine, отвечает на вопросы через GigaChat. Приложение работает в фоне: открывать его ради команды не нужно. И это только начало: новые возможности будут добавляться, а приложение — оптимизироваться.

## 🚀 Быстрый старт

1. **Установите Assist Voice на телефон** — APK со страницы [последнего выпуска](https://github.com/feed4me/Assist-Voice/releases/latest). С телефона потом удобнее всего ставить его на остальные устройства (см. [Установка](#-установка)).
2. **Выдайте разрешения.** На главном экране приложения — касанием по строкам списка или кнопкой <kbd>Выдать разрешения и включить службу (ADB)</kbd> (нужна включённая «Отладка по Wi-Fi», см. [Разрешения](#разрешения)).
3. **Включите службу:** Настройки → Специальные возможности → **Assist Voice**. Кнопкой ADB это делается само. Переключатель серый — см. [Ограниченные настройки](#ограниченные-настройки).
4. **Проверьте:** выйдите на домашний экран и скажите обычным темпом **«включи фонарик»** — эта команда работает сразу, без настройки. Выключить — «выключи фонарик».
5. **Создайте свою команду:** страница «Команды» → <kbd>Добавить слот</kbd> → тип «Приложение» → выберите, например, «Калькулятор» → в поле «Текст для запуска» напишите `калькулятор` → <kbd>Сохранить</kbd>. Теперь с домашнего экрана работает «открой калькулятор».
6. **Выберите режим прослушивания** на странице «Команды» (см. [Где слушать](#где-слушать)). Если команда нужна не постоянно — «Активация по кнопке», это самый экономный режим.
7. Не сработало — [Советы по распознаванию](#-советы-по-распознаванию) и [Настройка микрофона](#-настройка-микрофона).

> [!IMPORTANT]
> По умолчанию ассистент слушает **только на домашнем экране** (циферблат, рабочий стол) и не занимает микрофон, пока вы в других приложениях. Чтобы слушал всегда — режим «Во всех приложениях»; чтобы микрофон включался только по нажатию кнопки — «Активация по кнопке».

### Рекомендуемый способ: с телефона на все устройства

**Шаг 1. Телефон.** Скачайте APK на телефон, откройте файл и разрешите установку из этого источника, если система спросит. Затем — [Настройка](#-настройка).

**Шаг 2. Подготовьте устройство**, на которое будете ставить (часы, магнитолу, приставку). Оно должно быть в той же сети Wi-Fi, что и телефон.
1. Включите режим разработчика: **Настройки → О телефоне** (О часах, Об устройстве) → коснитесь номера сборки или версии 7 раз подряд.
2. В **Настройки → Для разработчиков** включите отладку:
   - **беспроводная отладка с кодом сопряжения**;
   - или **отладка по сети без кода**, на порту 5555: «Отладка по Wi-Fi», «ADB по сети» и т. п. Если такого пункта нет, её можно один раз включить с компьютера по USB: `adb tcpip 5555`.

   Прошивки бывают разные, поэтому и способ подключения у них разный.

   Особенности часов Huawei — [ниже](#часы-huawei).

**Шаг 3. Установите с телефона.**
1. В Assist Voice на телефоне: главный экран → <kbd>ADB</kbd>. Откроется список устройств вашей сети.
2. Выберите устройство. Если устройство подключается по коду — при первом подключении введите код сопряжения с его экрана; если без кода — на устройстве появится вопрос «Разрешить отладку?», ответьте «Разрешить». Нет в списке — введите адрес вручную.


> [!IMPORTANT]
> **Первое подключение по коду сопряжения.** Если устройство подключается по коду (беспроводная отладка с кодом сопряжения), то при **первом** подключении на нём нужно заранее открыть экран с кодом: «Отладка по Wi-Fi» → «Подключить устройство с помощью кода» (название зависит от прошивки). Пока этот экран не открыт, первое подключение не пройдёт — ни с телефона, ни кнопкой на самом устройстве. Дальше устройство подключается без кода.
3. В окне подтверждения проверьте производителя и модель и нажмите <kbd>Установить Assist Voice</kbd>. Телефон скачает последнюю версию, установит её, выдаст права и включит службу.
4. Assist Voice там уже стоит — <kbd>Выдать права</kbd> или <kbd>Переустановить Assist Voice</kbd> (ставится последняя версия, настройки сохраняются).
5. <kbd>Плагины</kbd> — поставить на это устройство ЯМузыку, а на часы Huawei ещё и распознавание Google (см. [Плагины](#-плагины)). Кнопка есть только в Assist Voice на телефоне.

**Шаг 4. Перенесите настройки и ключи.** Команды и настройки — кодом ([Перенос настроек](#-перенос-настроек)); ключи GigaChat и StarLine — кнопкой <kbd>Передать с телефона</kbd> на странице интеграции на часах.

### Часы Huawei

На часах Huawei обычная установка APK закрыта прошивкой, поэтому способ с телефона для них основной. Подходят часы, на которые можно ставить Android-приложения (Watch 3 / 3 Pro, Watch 4 / 4 Pro).

- Режим разработчика: **Настройки → Об устройстве → HarmonyOS** — 7 касаний; затем **Для разработчиков** → «Отладка по ADB» и «Отладка по Wi-Fi».
- Дальше Assist Voice **обновляется на часах сам** по беспроводной отладке (её нужно включить на время обновления).
- На часах Huawei кнопка выдачи прав заодно настраивает распознавание речи Google для вопросов GigaChat (см. [Плагины](#-плагины)).

> [!TIP]
> На статичных циферблатах Huawei с первым уровнем энергосбережения микрофон после включения экрана может не включиться, пока не коснуться экрана или ещё раз не нажать кнопку питания. Решение — в самом циферблате: **Настройки → Циферблат и рабочий экран → интерактивный вид циферблата → выключить энергосбережение** (подробнее — в [Решённых проблемах](#решённые-проблемы)).

### Другие часы на Android и Wear OS

Ставятся так же, с телефона, или обычной установкой APK. Если ассистент не узнаёт циферблат, включите режим «Во всех приложениях» (см. [Где слушать](#где-слушать)). Чтобы приложение оптимизировали под ваши часы, напишите разработчику в [Telegram](https://t.me/bynikolay) или [MAX](https://max.ru/channel_bynikolay) (см. [Поддержка и обратная связь](#-поддержка-и-обратная-связь)).

## 📲 Совместимость

### Системные требования

| | |
|---|---|
| **Android** | 8.0 и новее (плагин ЯМузыка — 10 и новее) |
| **Микрофон** | Встроенный или подключённый, доступный приложениям |
| **Место** | Без голосов озвучки — около 240 МБ (приложение вместе с офлайн-распознаванием речи); каждый скачанный голос — ещё около 63 МБ. Например, часы с одним голосом — около 295 МБ, телефон с двумя голосами — около 366 МБ |
| **Оперативная память** | Около 85–105 МБ на часах |
| **Интернет** | Не нужен для распознавания команд; нужен для интеграций, GigaChat, обновлений и скачивания голоса |
| **Проверено** | Часы Huawei Watch 3 / 3 Pro, Watch 4 / 4 Pro, OnePlus Watch, Samsung Galaxy Watch; телефоны на Android; магнитолы Teyes; ТВ-приставки Dune HD |

Android на разных устройствах и в разных версиях ведёт себя по-разному: где-то нужен один лишний переключатель, где-то экрана настроек нет вовсе. Многое из этого решает кнопка <kbd>Выдать разрешения и включить службу (ADB)</kbd> (или установка с телефона, которая выдаёт те же права).

### Ограниченные настройки

Если переключатель Assist Voice в спецвозможностях серый или система пишет «Ограниченная настройка»:
1. Попробуйте включить службу — система откажет. Без этой попытки пункт из шага 3 не появится.
2. Откройте **Настройки → Приложения → Assist Voice**.
3. Нажмите **⋮** (три точки вверху) → **«Разрешить ограниченные настройки»** и подтвердите.
4. Вернитесь в спецвозможности и включите службу.

Кнопка ADB снимает это ограничение сама.

### Google Play Защита

На устройствах с сервисами Google (на любой версии Android) Play Защита может предупредить при установке APK не из Google Play или заблокировать её: «Заблокировано Play Защитой», «Небезопасное приложение». Что делать:
- в окне предупреждения нажмите **«Подробнее»** → **«Всё равно установить»**, если такая кнопка есть;
- если установка блокируется совсем — на время установки отключите проверку: **Google Play → значок профиля → Play Защита → ⚙ → «Сканирование приложений с помощью Play Защиты»**, после установки включите обратно;
- установка с телефона по Wi-Fi (окно <kbd>ADB</kbd>, см. [Установка](#рекомендуемый-способ-с-телефона-на-все-устройства)) идёт по отладке, и это окно обычно не появляется.

### Автомагнитолы

- Включите режим **«Во всех приложениях»**: у магнитол свои «рабочие столы», и ассистент может их не узнать.
- Проверьте микрофон на странице «Настройки микрофона»: индикатор уровня должен двигаться от голоса. Не двигается — микрофон может быть занят громкой связью или собственным голосовым помощником магнитолы, или подключён только к модулю Bluetooth.
- Экранов разрешений на магнитоле часто нет — используйте кнопку ADB (с включённой отладкой по сети, см. [Установка](#рекомендуемый-способ-с-телефона-на-все-устройства)).

### ТВ-приставки

- Нужен микрофон, который видят приложения: встроенный в приставку, в пульте, USB или Bluetooth-гарнитура. Пример — Dune HD: микрофон в пульте работает с Assist Voice, и нажатия кнопок пульта приложение тоже видит. На других приставках микрофон пульта может быть доступен только их собственному помощнику — проверьте по индикатору уровня на странице «Настройки микрофона».
- Удобнее всего **«Активация по кнопке»**: привяжите свободную кнопку пульта — нажали и говорите. Если приставка не передаёт нажатия приложениям, включите режим **«Во всех приложениях»**.
- Страницы приложения листаются кнопками пульта ← →, а также Page Up / Page Down и переключением каналов.
- Экранов «Поверх других приложений» и спецвозможностей на Android TV часто нет — используйте кнопку ADB.

## 🔧 Настройка

### Разрешения

На главном экране приложения плашка показывает итог: «Все разрешения предоставлены» или «Не все разрешения предоставлены (N)». Под ней список: касание строки открывает нужный экран системы.

| Разрешение | Зачем | Примечание |
|---|---|---|
| 🎤 Микрофон | Слышать команды | — |
| 👥 Контакты | Звонки по слову и по имени | — |
| 📞 Телефон | Звонить и отвечать на входящие | — |
| 🪟 Поверх других приложений | Иконка микрофона, карточки с результатом, список выбора | — |
| 🔔 Уведомления | Таймер, свёрнутый диалог GigaChat, служба | Запрашивается не на всех устройствах |
| 📦 Установка приложений | Обновление в один тап | Не нужно на часах Huawei: там обновление идёт по ADB |

**Кнопка <kbd>Выдать разрешения и включить службу (ADB)</kbd>** подключается к самому устройству по отладке и выдаёт разрешения разом, в том числе те, у которых на прошивке нет экрана настроек. При установке с телефона (окно <kbd>ADB</kbd>) выдаётся то же самое. Кроме того, кнопка даёт:
- работу без ограничений экономии батареи;
- снятие [ограниченных настроек](#ограниченные-настройки);
- автоматическое восстановление службы после перезагрузки и сбоев.

Перед нажатием включите отладку по сети на этом же устройстве; если оно подключается по коду сопряжения — при первом подключении откройте экран с кодом (см. [Установка](#рекомендуемый-способ-с-телефона-на-все-устройства)).

### Служба специальных возможностей

Assist Voice работает как служба специальных возможностей: так система реже выгружает его из памяти, и ассистент слышит команды, не будучи открытым.

> [!NOTE]
> Служба **не читает** текст на экране и ваш ввод. Ей нужно только название открытого приложения, чтобы понимать, домашний ли это экран. В режиме «Активация по кнопке» она ещё получает нажатия кнопок устройства, остальные нажатия проходят как обычно.

Включается здесь: **Настройки → Специальные возможности → Assist Voice** (иногда в подразделе «Установленные приложения» или «Скачанные приложения»). Экрана нет или переключатель серый — кнопка ADB или [ограниченные настройки](#ограниченные-настройки).

Выключить ассистента целиком можно на карточке «Выключение ассистента» на главном экране приложения.

## 📢 Голосовые команды

### Как устроена команда

Почти любая команда — это **глагол + ваше слово**:

```
 [слово-активатор]    открой    калькулятор
  (если задано)       глагол    ваше слово
```

Глагол защищает от случайных срабатываний: ассистент реагирует, только когда подряд прозвучали и глагол, и слово. Поэтому фразу говорят **целиком** и **в правильном порядке**.

> [!TIP]
> Не помните фразу? Откройте **«Справочник команд»**: там каждая фраза показана уже с учётом вашего активатора, режима и VIP.

### Свои команды (слоты)

Страница «Команды» → <kbd>Добавить слот</kbd>. Есть четыре типа:

| Тип | Глаголы | Пример | Что делает |
|---|---|---|---|
| 📱 **Приложение** | открой, запусти | «открой почту» | Открывает приложение. Если у приложения есть отдельные экраны или ярлыки (такое бывает редко), в поле «Экран» можно выбрать нужный — например, в Яндекс Браузере сразу открыть голосового ассистента Алису. |
| 📞 **Контакт** | позвони, набери | «позвони маме» | Звонит на выбранный номер |
| 🔧 **Настройки и система** | открой, запусти, сделай | «сделай скриншот», «открой блютус» | Экран настроек (Wi-Fi, Bluetooth, звук…), панель или действие: уведомления, быстрые настройки, блокировка экрана, скриншот, «назад», «домой», меню питания. Показываются только те, что есть на устройстве |
| 📍 **Место на карте** | открой, запусти, найди | «найди магазины» | Открывает место в приложении карт: по координатам (`55.7539, 37.6208`) — нужно приложение карт или навигатор, который принимает координаты, — или по запросу («магазины») |

**Правила для слова команды**
- Пишите так, как произносите; поддерживается только русский язык. Значение имеет каждая буква, чёткость произношения окончаний и фразы в целом.
- **Числа — словами:** `пятый канал`, а не `5 канал`.
- Слово может быть фразой («маршрут до дома»), тогда говорить нужно её целиком.
- При сохранении приложение проверяет, **знает ли распознаватель все слова** и **не занята ли фраза** другой командой. Если что-то не так, появится подсказка.
- Команду из одного слова сохранить можно, но приложение предупредит: она может сработать случайно в разговоре.

Кнопка <kbd>Синхронизировать приложения и контакты</kbd> обновляет списки, если вы только что установили приложение или добавили контакт.

### Слово-активатор

Необязательное общее слово перед командами, например **«часы»**: «часы, открой карты». Снижает число случайных срабатываний, если вокруг много разговоров.

- Поле **«Слово-активатор»** на странице «Команды» (пусто — выключено).
- Под ним список **«Применить к»**: Музыка, Фонарик, Исходящие звонки, Входящие звонки, Приложения, Таймер. Снимите галочку — и этой группе активатор не нужен. По умолчанию исключены входящие звонки.
- У Умного дома Яндекса, Hikvision и StarLine **свои** слова-активаторы, по умолчанию пустые. GigaChat общего активатора не требует никогда: его слово-активатор и есть команда.

### Где слушать

Переключатель на странице «Команды»:

| Режим | Когда микрофон слушает | Кому подходит |
|---|---|---|
| 🏠 **На домашнем экране** (по умолчанию) | На циферблате или рабочем столе, а также пока открыт сам Assist Voice | Часы и телефон: микрофон не занят, пока вы в других приложениях |
| 🌐 **Во всех приложениях** (переключатель «Где слушать» включён, под ним «Работает во всех приложениях») | Всегда, поверх любых приложений | Магнитола, приставка, устройства, где ассистент не узнаёт домашний экран |
| 🔘 **Активация по кнопке** — самый экономный | Только после нажатия привязанной кнопки; в остальное время микрофон выключен | Все, кому важна батарея; шумные места |

**Активация по кнопке — самый энергоэффективный режим.** В покое микрофон выключен полностью, поэтому ни запись, ни распознавание не расходуют батарею, а случайные разговоры рядом ничего не запускают. Нажмите <kbd>Привязать кнопку</kbd> и в течение 15 секунд нажмите на устройстве нужную кнопку нужным жестом: одно нажатие, двойное или долгое. Дальше это нажатие включает микрофон до выполненной команды или 5 секунд тишины (не дольше 15 секунд). Привязанная кнопка этим жестом перестаёт делать своё обычное дело (например, долгое нажатие громкости перестанет менять громкость). <kbd>Сбросить кнопки</kbd> отменяет привязку.

В любом режиме микрофон слушает, пока открыты окно GigaChat, таймер, белый экран фонарика, список выбора и окно камеры, а также во время входящего звонка.

### Встроенные команды

Работают сразу, настраивать не нужно. Если задано общее слово-активатор и группа не исключена, его говорят в начале.

<details>
<summary><b>🔦 Фонарик</b></summary>

- «включи фонарик», «выключи фонарик»

На телефоне включится вспышка. Там, где её нет, экран зальётся белым на максимальной яркости. Белый экран выключается той же командой или касанием.

</details>

<details>
<summary><b>🎵 Музыка</b></summary>

С любым плеером, который сейчас играет:
- «включи музыку», «выключи музыку» (а также «пауза», «поставь на паузу»)
- «следующий трек», «предыдущий трек», «сначала»
- «продолжи воспроизведение»

Только с приложением «ЯМузыка byNikolay» (клиент Яндекс Музыки для часов, ставится отдельно — см. [Плагины](#-плагины)):
- «включи волну» («включи мою волну»)
- «включи любимую музыку» («включи любимые треки»)
- «включи сохранённые треки»
- «лайк», «дизлайк»

«Пауза», «сначала», «лайк» и «дизлайк» срабатывают, только когда музыка играет: обычное слово в разговоре трек не перемотает.

</details>

<details>
<summary><b>📲 Входящий звонок</b></summary>

- Принять: «прими звонок», «прими вызов», «возьми трубку», «возьми телефон», «ответь», «ответь на звонок»
- Отклонить: «отклони звонок», «отклони вызов», «отклони», «сбрось звонок», «не отвечай»

Работает, только пока телефон звонит.

</details>

<details>
<summary><b>⏰ Таймер</b></summary>

- Запустить: «таймер на пять минут», «поставь таймер на полчаса», «таймер на час пятнадцать минут»
- Изменить: «добавь минуту», «добавь к таймеру тридцать секунд», «ещё пять минут», «убавь две минуты», «убери минуту от таймера»
- Узнать: «сколько осталось», «сколько времени осталось»
- Показать: «открой таймер», «покажи таймер»
- Остановить: «отмени таймер», «выключи таймер», «останови таймер»

Время — как удобно: «полминуты», «полторы минуты», «пять с половиной минут», «час с половиной», «две минуты тридцать секунд», до 24 часов. Таймер один: новый заменяет текущий. Пока открыто окно таймера, «стоп» или «отмена» останавливают его, а «закрой» только закрывает окно. В конце сигнал и 5 секунд вибрации.

</details>

<details>
<summary><b>👤 Звонок и запуск по имени</b> <img src="https://img.shields.io/badge/-VIP-E3B341?style=flat-square" alt="VIP"></summary>

Включаются галочками «Свободный звонок по имени» и «Свободный запуск приложений» на странице «Команды».

- «позвони ‹имя или фамилия›», «набери ‹…›» — любой контакт из телефонной книги, имя и фамилия в любом порядке и падеже («позвони Петровой Анне»).
- «открой ‹название›», «запусти ‹название›» — любое установленное приложение.

Если подходит несколько вариантов, появится нумерованный список: назовите номер («два») или коснитесь строки. Закрыть — «стоп» или «закрой». Ваши слоты всегда в приоритете.

Если ассистент упорно не понимает название приложения или имя контакта, заведите для него слот на странице «Команды» со своим словом — слот срабатывает по точной фразе.

</details>

<details>
<summary><b>❌ Слова закрытия окон</b></summary>

Для списка выбора, окна камеры, таймера и диалога GigaChat:
- **отменить:** «стоп», «стой», «хватит», «отбой», «отмена», «отмени», «отменить»
- **только закрыть:** «закрой», «закрыть», «выйти», «выход»

Говорят только это слово (можно с названием окна: «закрой камеру»). Фраза, в которой оно просто встречается, окно не закроет.

</details>

Команды интеграций — в их разделах: [Умный дом](#умный-дом-яндекса), [GigaChat](#gigachat), [StarLine](#starline), [Hikvision](#hikvision).

**Что вы увидите после команды.** Короткая вибрация (если включена «Вибрация при команде» и действие действительно что-то сделает). Если действие не удалось, появится карточка с причиной отказа.

## 🎯 Советы по распознаванию

Частая жалоба: «микрофон меня слышит, а команда не срабатывает». Обычно причина — в одном из пунктов ниже.

| ❌ Не так | ✅ А так |
|---|---|
| По слогам или с долгими паузами: «открой… каль-ку-ля-тор» | Одной фразой, в обычном темпе, как говорите человеку |
| Начинать говорить в ту же долю секунды, когда загорелся экран | Убедиться, что микрофон в активном состоянии (иконка микрофона в цвете «при записи»), и только потом говорить |
| Шёпотом или с вытянутой руки в шумной комнате | Обычным голосом, часы в 20–30 см от рта |
| Чужой глагол: «найди почту» для слота-приложения | Глагол своего типа: открой/запусти, позвони/набери, сделай, найди |
| Без слова-активатора, если оно задано | Сначала активатор: «часы, открой карты» |
| Другим словом: «открой калькулятор» при слоте «счёты» | Ровно ваше слово — сверьтесь со «Справочником команд» и списком слотов |
| Говорить не на домашнем экране (в режиме по умолчанию) | Выйти на циферблат или рабочий стол, или включить режим «Во всех приложениях» |

**Почему так строго?** Команды распознаются прямо на устройстве, без интернета. Встроенный распознаватель лучше всего понимает обычную речь в обычном темпе и хуже — растянутую по слогам, шёпот и слова, которых нет в его русском словаре (поэтому каждое слово проверяется при сохранении команды).

> [!TIP]
> Говорите медленно или с паузами? Не переучивайтесь — увеличьте **«Хвост»** на странице «Настройки микрофона»: ассистент будет дольше ждать конца фразы.

## 🎤 Настройка микрофона

Страница «Настройки микрофона». Здесь подбирается, как ассистент отличает вашу команду от тишины и шума. Индикатор показывает громкость с микрофона в реальном времени, «пик» — максимум (<kbd>Сбросить пик</kbd> обнуляет).

| Настройка | Что делает | Когда менять |
|---|---|---|
| **Порог** | С какой громкости звук считается речью | Не слышит совсем → **уменьшить**. Реагирует на шум, телевизор, ветер → **увеличить** |
| **Преролл** | Сколько звука **до** срабатывания добавляется в начало | Обрезается начало («крой карты» вместо «открой карты») → **увеличить** |
| **Хвост** | Сколько тишины ждать, прежде чем считать фразу законченной | Говорите медленно, обрезается конец → **увеличить**. Долго «думает» после команды → **уменьшить** |
| **Не выключать экран после команды** | Сколько секунд экран не гаснет после команды (0 — выключено) | Чтобы успеть увидеть результат на часах |

**Как подобрать порог**
1. Помолчите несколько секунд — это уровень фона.
2. Скажите команду обычным голосом с обычного расстояния — посмотрите на «пик».
3. Поставьте порог между фоном и пиком, ближе к фону.
4. Проверьте: когда вы говорите, надпись под уровнем на этой странице меняется с «Ждёт» на «Распознаёт».

> [!IMPORTANT]
> **На этой странице видно, где проблема.** Пока вы говорите, надпись остаётся «Ждёт» — вас не слышно: уменьшите порог. Появляется «Распознаёт», но команда не срабатывает — не распознана фраза: см. [Советы по распознаванию](#-советы-по-распознаванию).

## 🔊 Озвучка и таймер

### Озвучка

Страница «Настройки» → «Озвучка». Офлайн-голоса **Руслан** и **Ирина** читают ответы GigaChat, остаток таймера и результаты команд Умного дома, StarLine и Hikvision. Синтез идёт на устройстве, текст никуда не уходит.

- Голос скачивается один раз кнопкой-дискетой (около 63 МБ), **по Wi-Fi или мобильной сети**. Через Bluetooth от телефона загрузка не идёт — выключите Bluetooth на часах на время скачивания.
- Значок воспроизведения даёт послушать голос, корзина удаляет его.
- Ползунки скорости (80–150 %) и громкости.
- Если к часам подключены наушники, ответы звучат только в наушниках; без наушников — из динамика часов. Сигнал таймера звучит и в динамике, и в наушниках.
- Что озвучивать, выбирается на странице каждой функции: «Отвечать голосом» у GigaChat, «Статус голосом» у интеграций, «Остаток голосом» у таймера. Пока голос не скачан, эти галочки неактивны.

### Настройки таймера

Страница «Настройки» → «Таймер»: ответ на «сколько осталось» текстом и/или голосом, громкость сигнала, <kbd>Проверить</kbd> и пять звуков: «Сигнал», «Мягкий», «Колокольчик», «Нарастающий», «Сирена».

## 🔄 Перенос настроек

Настроили всё на телефоне и хотите то же на часах? Или меняете часы на новые?

1. На старом устройстве: главный экран → «Перенос конфигурации» → <kbd>Получить код</kbd>. Запишите код (есть <kbd>Копировать код</kbd>).
2. На новом устройстве: там же → <kbd>Принять по коду</kbd> → введите код → подтвердите замену настроек.

| ✅ Переносится | ❌ Не переносится |
|---|---|
| Слоты (команды), слово-активатор и его исключения | Ключи GigaChat и StarLine, логины и пароли Hik-Connect и StarLine, вход в Умный дом Яндекса |
| Настройки микрофона и время работы экрана | VIP (он привязан к устройству) |
| Иконка микрофона (размер — только между устройствами одного типа) | Скачанные голоса озвучки |
| Команды Умного дома Яндекса и его слово-активатор | Привязка кнопок |
| Галочки озвучки, ответ таймера и звук сигнала | Команды и слова-активаторы Hikvision и StarLine, слово-активатор GigaChat |

> [!NOTE]
> Код хранит **последний** экспорт устройства: новый <kbd>Получить код</kbd> заменяет предыдущий. Переносите между одинаковыми версиями приложения; если на новом устройстве версия старее, приложение попросит сначала обновиться.

## 👑 VIP-доступ

VIP открывает: звонок любому контакту по имени, запуск любого приложения по названию, Умный дом Яндекса, GigaChat, Hikvision и StarLine.

> [!TIP]

1. Подпишитесь на Telegram-канал **[@bynikolay](https://t.me/bynikolay)**.
2. На главном экране приложения коснитесь плашки **«VIP не активен»** — откроется экран VIP с кодом.
3. Отправьте код боту — любым из способов:

4. Готово. Дальше VIP продлевается сам.

Пока VIP не активен, его функции видны приглушёнными, с золотой плашкой «VIP», и ничем себя не навязывают.

## 🔗 Интеграции

Все интеграции требуют [VIP](#-vip-доступ) и работают через интернет: команда уходит прямо в сервис.

| Сервис | Что умеет | Что нужно |
|---|---|---|
| 💡 [Умный дом Яндекса](#умный-дом-яндекса) | Свет, розетки, климат и другие устройства «Дома с Алисой» | Аккаунт Яндекса |

| 🚪 [Hikvision](#hikvision) | Калитка, ворота, камеры | Аккаунт Hik-Connect |

### Умный дом Яндекса

<img src="https://img.shields.io/badge/-VIP-E3B341?style=flat-square" alt="VIP"> Включайте и выключайте устройства и группы из «Дома с Алисой» своими фразами.

**Подключение**
1. «Интеграции» → «Умный дом Яндекса».
2. Приложение покажет код и QR-код. Откройте указанную страницу Яндекса на любом устройстве, войдите в свой аккаунт и введите код — или отсканируйте QR.
3. Когда появится «Умный дом Яндекса подключён», откройте «Устройства» или «Группы устройств».

**Команды**
- У каждого устройства и группы **две команды**: включения и выключения, каждая — полная фраза: «включи свет на кухне» / «выключи свет на кухне». Поле выключения само подстраивается под включение, пока вы его не правили.
- Группы удобны для «весь свет»: «выключи весь свет» одной командой.
- Слово-активатор Умного дома своё, по умолчанию пустое. Задайте, например, «дом», если команды срабатывают случайно: «дом, включи свет».
- «Статус текстом» — карточка с результатом, «Статус голосом» — озвучка. Об ошибке карточка скажет всегда.
- На экране устройства есть и ручные переключатели.

> [!TIP]
> Названия, похожие по звучанию, различаются хуже: «свет в зале» и «свет в спальне» надёжнее, чем «лампа два» и «лампа двадцать два».

### GigaChat

<img src="https://img.shields.io/badge/-VIP-E3B341?style=flat-square" alt="VIP"> + личный ключ GigaChat (бесплатный) + интернет. Вопрос голосом — ответ на экране и, если включено, голосом. Вопрос можно диктовать через распознавание Google или встроенное офлайн-распознавание.

#### Как получить ключ GigaChat

Ключ личный и бесплатный: вопросы тратят **вашу** бесплатную квоту Сбера для физических лиц (её размер — на сайте Сбера).

1. Откройте личный кабинет Сбера для разработчиков — [developers.sber.ru](https://developers.sber.ru) (Studio) — и войдите через Сбер ID.
2. Нажмите **«Создать проект»** и выберите **GigaChat API**.
3. Проект появится в списке **«Все проекты»** (например, «Мой GigaChat API») с отметкой «Доступ получен». Откройте его.
4. На странице проекта видно бесплатный тариф Freemium и остаток бесплатных токенов. В блоке **«Ключевые действия»** нажмите **«Настроить API»** (Перейти к ключам).
5. В разделе **«Ключ авторизации»** нажмите **«Получить новый ключ»** и скопируйте **Authorization key** — длинную строку из букв и цифр (около 90 символов). Сохраните её: Сбер показывает ключ один раз. Если ключ потерялся — получите новый той же кнопкой и введите его в Assist Voice заново.

- **На телефоне:** «Интеграции» → «GigaChat» → <kbd>Ввести ключ</kbd> → вставьте ключ целиком → <kbd>Сохранить</kbd>.
- **На часах:** набирать 90 символов неудобно, поэтому <kbd>Передать с телефона</kbd>. Отсканируйте QR камерой телефона, вставьте ключ на открывшейся странице и нажмите «Передать на часы». Ключ шифруется в браузере телефона и расшифровывается только на часах.

Ключ хранится только на устройстве в зашифрованном виде. <kbd>Удалить ключ</kbd> стирает его.

#### Как спрашивать

1. Скажите **слово-активатор GigaChat** — это слово, которое открывает окно вопроса. Оно задаётся на странице GigaChat в поле «Слово-активатор» и видно в «Справочнике команд».
2. **Дождитесь окна с подписью «Слушаю…»** и только потом говорите вопрос. Сказанное вместе со словом-активатором в вопрос не попадает.
3. Говорите свободно: слова появляются на экране, после короткой паузы вопрос уходит сам.
4. Ответ появится на экране; с галочкой «Отвечать голосом» — ещё и прозвучит (нужен скачанный голос, см. [Озвучка](#озвучка)).
5. Если включена иконка «авто» (по умолчанию да), после ответа можно сразу задать следующий вопрос без слова-активатора: короткая вибрация и мягкий сигнал — ассистент снова слушает. Модель помнит последние вопросы диалога.

**Управление диалогом**

| Голосом | Кнопкой | Что делает |
|---|---|---|
| «очистить» | <kbd>Очистить</kbd> | Стирает историю, диалог начинается заново |
| «отмена», «стоп», «закрой» | <kbd>Отменить</kbd> | Закрывает окно и стирает историю |
| «отправить» | <kbd>Отправить</kbd> | Отправляет вопрос, если он не ушёл сам |
| «открой гига чат», «покажи гига чат» | касание уведомления | Возвращает свёрнутый диалог |

Иконка **«авто»**: зелёная — вопрос уходит сам, красная — вы правите текст и отправляете вручную. Рядом иконки вибрации и звука сигнала «слушаю снова». Свёрнутый диалог остаётся в шторке уведомлением «GigaChat»; через 5 минут без действий он сбрасывается.

**Настройки на странице GigaChat**
- <kbd>Модель</kbd> — выбор из моделей, доступных вашему аккаунту. По умолчанию — та, у которой самая большая бесплатная квота.
- **«Распознавание голоса только офлайн»** — см. ниже.

#### Распознавание вопроса: Google или офлайн

Команды Assist Voice всегда распознаёт сам, на устройстве. А **вопрос для GigaChat** можно диктовать через распознавание речи Google:

| | Google | Офлайн |
|---|---|---|
| **Когда используется** | По умолчанию, если на устройстве есть приложение Google или «Речевые сервисы Google» | Если Google нет, если он не ответил или стоит галочка «Распознавание голоса только офлайн» |
| **Особенности** | Обработка — по правилам Google | Звук не покидает устройство; лучше всего понимает обычную речь в обычном темпе |
| **Подпись в окне** | «Инициализация…», затем «Слушаю…» | «Слушаю…» и короткий сигнал |

Если Google не ответил, ассистент сам переходит на офлайн-распознавание со своим звуковым сигналом и до закрытия окна вопроса больше к Google не обращается. На часах Huawei распознавание Google настраивает кнопка ADB; для них есть отдельная сборка в [Плагинах](#-плагины).

> [!WARNING]
> GigaChat не знает свежих новостей, погоды и курсов валют: доступа к интернету у модели нет, поэтому она может ошибаться и выдумывать ответы. В следующих версиях появятся навыки, которые добавят такие функции.

### StarLine

<img src="https://img.shields.io/badge/-VIP-E3B341?style=flat-square" alt="VIP"> + автомобиль со StarLine + личные ключи разработчика StarLine (бесплатные). Двигатель, охрана, климат и состояние машины голосом с часов или телефона.

#### Как получить ключи StarLine

Ключи — **AppId** и **Secret** — у каждого свои. Приложение работает от вашего имени и только с автомобилями вашего аккаунта.

1. Откройте страницу для разработчиков **[my.starline.ru/developer](https://my.starline.ru/developer)** и войдите **под той учётной записью StarLine, к которой привязана машина**.
2. Подайте заявку: заполните форму регистрации разработчика (ФИО, телефон, email, цель использования API), согласитесь с положением об использовании открытого API и нажмите «Отправить». Решение по заявке принимает оператор StarLine исходя из цели — напишите её понятно, например: «Голосовое управление своим автомобилем с часов и телефона через приложение Assist Voice».
3. Дождитесь одобрения заявки.
4. После одобрения на странице **«Разработчикам»** нажмите <kbd>Создать приложение</kbd>, назовите его как угодно (например, «Assist Voice») и скопируйте **AppId** (идентификатор приложения) и **Secret** (пароль приложения). Приложение работает только с вашей учётной записью — так и задумано.

#### Как ввести ключи и войти

1. «Интеграции» → «StarLine» → <kbd>Ввести ключи</kbd> → AppId, затем Secret.
   На часах удобнее <kbd>Передать с телефона</kbd>: отсканируйте QR телефоном, введите AppId и Secret на открывшейся странице и нажмите «Передать на часы».
2. Введите **логин и пароль** аккаунта StarLine → <kbd>Войти</kbd>. Пароль нигде не сохраняется.
3. Попросит StarLine **код из СМС** или **код с картинки** — поля появятся на той же странице.
4. Откройте <kbd>Автомобили</kbd>. Если машина одна, сразу откроется список её функций.

#### Функции и команды

Состав функций зависит от машины и сигнализации — приложение показывает всё, что она умеет:

| Вид | Примеры | Команды |
|---|---|---|
| 🔁 **Включить / выключить** | двигатель, охрана, охрана без звука, подогреватель, подогрев руля, сидений, стёкол, вентиляция, автоклимат, сервисный режим, дополнительные каналы | Две: «заведи машину» / «заглуши машину», «поставь на охрану» / «сними с охраны»; плюс ручной переключатель |
| 👉 **Действие** | сигнал («найди машину»), багажник, тревога, гибкая логика | Одна команда и кнопка «выполнить сейчас» |
| 📋 **Справка** | состояние машины, температура, напряжение аккумулятора, баланс SIM-карты, маршрут до машины | Одна команда, ответ карточкой и/или голосом. «Построй маршрут до машины» передаёт координаты машины в навигатор — нужен навигатор, который принимает координаты |

Есть климат — «установи климат на двадцать два» (от 15 до 29).

В ответе — «… выполнен», если машина подтвердила, или «принята», если подтверждение не успело прийти. Галочки «Статус текстом» и «Статус голосом» — как у Умного дома.

**Моточасы.** Для каждой машины на странице StarLine — моточасы. Нажмите секундомер, и пойдёт отсчёт с этого момента: удобно для замены масла.

#### Как лучше настроить команды StarLine

> [!IMPORTANT]
> После подключения **ни одна голосовая команда StarLine не включена**. Вы сами задаёте фразы только для нужного; тексты по умолчанию лишь подставляются как подсказка.

- **Задайте слово-активатор StarLine** (например, «машина»): «машина, заведи двигатель». Для двигателя, охраны и тревоги это снижает риск случайного срабатывания.
- **Никаких опасных команд из одного слова** («заведи», «тревога»): минимум глагол и существительное.
- **Включите «Статус голосом»** для двигателя и охраны — подтверждение слышно, не глядя на экран.
- **Разводите похожие фразы:** «поставь на охрану» и «поставь на охрану без звука» начинаются одинаково, такую пару приложение сохранить не даст. Используйте, например, «тихая охрана».
- Команды StarLine не переносятся кодом конфигурации — на новом устройстве задайте их заново.

<img src="https://img.shields.io/badge/-VIP-E3B341?style=flat-square" alt="VIP"> + аккаунт Hik-Connect. Калитка и ворота (реле домофона) и камеры голосом.

| 🎵 **ЯМузыка byNikolay** | Неофициальный клиент Яндекс Музыки для часов: «Моя волна», любимые треки, плейлисты, скачивание для прослушивания без сети; отправка трека на другие устройства аккаунта — в разработке. Управляется голосом из Assist Voice (см. [Музыка](#встроенные-команды)) | Android 10+, прежде всего часы | [APK](https://github.com/feed4me/Assist-Voice/raw/main/plugins/YaMusic.apk) |
| 🗣 **Речевые сервисы Google** (сборка для часов Huawei) | Системное распознавание речи с русским языком для диктовки вопросов GigaChat. На часах Huawei сервисов Google изначально нет — эта сборка подготовлена специально для них | Часы Huawei | [APK](https://github.com/feed4me/Assist-Voice/raw/main/plugins/GoogleSpeechServices.apk) |

### Как установить плагин

Плагины раздаются **с телефона**: на часах, магнитолах и приставках этих кнопок нет.

- **ЯМузыка на сам телефон:** главный экран → <kbd>Плагины</kbd> (под <kbd>Проверить обновления</kbd>) → <kbd>Установить</kbd>, затем подтвердите установку в окне системы. Если система попросит разрешить установку приложений из Assist Voice — разрешите и нажмите <kbd>Установить</kbd> ещё раз. На этом экране видно, какая версия ЯМузыки установлена и какая последняя: есть новее — кнопка <kbd>Обновить до …</kbd>, стоит та же — <kbd>Переустановить</kbd>.
- **На другое устройство:** главный экран → <kbd>ADB</kbd> → выберите устройство (как в [установке с телефона](#-установка)) → <kbd>Плагины</kbd>. Видно, что уже установлено и какой версии, и какая версия последняя; ЯМузыка предлагается любому устройству, <kbd>Распознавание Google</kbd> — только часам Huawei. После установки распознавания Assist Voice сам назначит его распознавателем речи и выведет из-под экономии батареи.

## 🩺 Устранение неполадок

### Команда не срабатывает

```mermaid
flowchart TD
    A["Команда не сработала"] --> B{"Иконка микрофона<br/>видна?"}
    B -- "нет" --> B1["Служба выключена, не домашний экран,<br/>не нажата кнопка активации<br/>или нет «Поверх других приложений»"]
    B -- "да" --> C{"«Настройки микрофона»:<br/>при речи «Распознаёт»?"}
    C -- "нет" --> C1["Вас не слышно:<br/>уменьшите «Порог», говорите ближе"]
    C -- "да" --> E["Фраза не распознана:<br/>темп, глагол, активатор, слово слота"]
```

По шагам — обычно ответ находится на первых трёх:

1. **Ассистент включён?** Главный экран приложения: «Все разрешения предоставлены», служба включена, ассистент не выключен на карточке «Выключение ассистента».
2. **Слушает ли он сейчас?** В режиме по умолчанию — только на циферблате или рабочем столе: не открыто ли другое приложение? В режиме «Активация по кнопке» — только после нажатия привязанной кнопки.
3. **Услышал ли он вас?**
   - иконки микрофона нет совсем → включите «Показывать» на странице «Иконка микрофона» и проверьте «Поверх других приложений»;
   - на странице «Настройки микрофона» при речи остаётся «Ждёт» → вас не слышно: уменьшите **Порог**, говорите ближе;
   - появляется «Распознаёт», но ничего не происходит → фраза не распознана, шаг 4.
4. **Правильная ли фраза?** Откройте «Справочник команд» и скажите фразу **ровно** как там написано. См. [Советы по распознаванию](#-советы-по-распознаванию).
5. **Обрезается начало или конец?** Увеличьте **Преролл** (начало) или **Хвост** (конец).
6. **Не помогло** → [отправьте лог](#как-отправить-лог-разработчику) и напишите, какую фразу говорили и когда.

### Ассистент перестал слушать

- **После перезагрузки или со временем.** Прошивка могла выключить службу или выгрузить приложение. Нажмите <kbd>Выдать разрешения и включить службу (ADB)</kbd> ещё раз: после этого приложение само пытается вернуть службу после перезагрузки и сбоев.
- **Экономия батареи.** Снимите для Assist Voice ограничения экономии батареи в настройках системы или нажмите кнопку ADB — она делает это сама.
- **Часы Huawei, статичный циферблат.** См. [Решённые проблемы](#решённые-проблемы).

### Срабатывает, когда не просили

- Увеличьте **Порог** — перестанет реагировать на далёкую речь и телевизор.
- Задайте **слово-активатор**.
- Замените короткие и частые слова в слотах на более редкие.
- Попробуйте **«Активация по кнопке»**.

### Как отправить лог разработчику

1. Главный экран → карточка «Диагностика». Галочка «Записывать лог» включена по умолчанию.
2. Воспроизведите проблему.
3. Нажмите <kbd>Отправить лог</kbd> и напишите в бот поддержки [@AssistVoiceSupport_Bot](https://t.me/AssistVoiceSupport_Bot), что делали и во сколько. Укажите **ID устройства** с карточки «Диагностика» — так лог найдут быстрее.

| ✅ В логе есть | ❌ В логе нет |
|---|---|
| Модель, версия Android, тип устройства | Слов, которые вы говорили, и звука |
| Статус разрешений и ваши настройки | Имён и номеров контактов |
| Технические события: команда распознана или нет, сколько слов, уверенность | Ключей, паролей, вопросов и ответов GigaChat |

<kbd>Очистить лог</kbd> стирает журнал с устройства.

## 🐞 Известные проблемы и решения

### Решённые проблемы

Проблемы, с которыми сталкивались пользователи, и как они решены. Если вы видите похожее — сначала проверьте здесь.

<details>
<summary><b>⌚ Часы Huawei: на статичном циферблате микрофон не включался после включения экрана</b></summary>

| | |
|---|---|
| **Симптом** | После включения экрана микрофон не включался: чтобы ассистент начал слушать, нужно было коснуться экрана или ещё раз нажать кнопку питания |
| **Причина** | Статичные циферблаты Huawei с первым уровнем энергосбережения не «будят» часы полностью при включении экрана, и микрофон стороннего приложения не включается. Обойти это из приложения нельзя |
| **Решение** | **Настройки → Циферблат и рабочий экран → интерактивный вид циферблата → выключить энергосбережение.** После этого микрофон включается сразу после включения экрана |

</details>

<details>
<summary><b>📱 Ассистент «включён», но не слушает после того, как система его выгрузила</b></summary>

| | |
|---|---|
| **Симптом** | В спецвозможностях Assist Voice включён, а команды не работают; в шторке висит старое уведомление |
| **Причина** | Прошивка выгрузила приложение (например, при открытии камеры), а служба осталась «включённой» только на словах |
| **Решение** | Исправлено в приложении: при следующем запуске оно само обнаруживает такую службу и перезапускает её. Кнопка ADB дополнительно позволяет приложению самому возвращать службу после перезагрузки и сбоев |

</details>

> [!NOTE]
> Все ограничения ниже — временные. Как быстро они будут сняты, напрямую зависит от активности сообщества: сообщений о проблемах с логами, идей и [поддержки проекта](#-поддержка-и-обратная-связь).

| Ограничение | Почему и что делать |
|---|---|

## ❓ Часто задаваемые вопросы

### Распознавание и команды

<details>
<summary><b>Микрофон меня слышит («Распознаёт»), но команда не срабатывает</b></summary>

Звук слышен, но фраза не совпала с командой. Чаще всего:
- по слогам или с паузами — скажите одной фразой или увеличьте «Хвост»;
- начали слишком рано и первое слово обрезалось — подождите полсекунды или увеличьте «Преролл»;
- не тот глагол: приложения — «открой/запусти», контакты — «позвони/набери»;
- забыли слово-активатор;
- слово в слоте записано не так, как произносится (латиница, цифры);
- ассистент не на домашнем экране.

См. [Советы по распознаванию](#-советы-по-распознаванию) и [Устранение неполадок](#команда-не-срабатывает).

</details>

<details>
<summary><b>Нужен ли интернет?</b></summary>

Для распознавания команд — нет. Интернет нужен тому, что работает через сеть по своей природе: Умный дом Яндекса, Hikvision, StarLine, GigaChat, проверка обновлений, скачивание голоса, отправка лога и перенос настроек.

</details>

<details>
<summary><b>Можно ли придумать любую фразу?</b></summary>

Да, любой длины. Два условия: каждое слово есть в словаре распознавателя (обычные русские слова; проверяется при сохранении), и фраза не совпадает с другой командой и не начинается так же. Глагол слотов («открой», «позвони», «сделай», «найди») фиксирован; у интеграций фраза полностью ваша.

</details>

<details>
<summary><b>Приложение пишет, что слово «не знает»</b></summary>

Такого слова нет в словаре распознавателя: обычно это латиница, цифры, аббревиатуры, редкие фамилии или сленг. Для звонков по имени (VIP) это не нужно: имена ищутся по похожему звучанию.

</details>

<details>
<summary><b>«Открой» и название работает не у всех приложений</b></summary>

Без VIP открываются приложения, для которых вы создали слот. С VIP включите «Свободный запуск приложений» — откроется любое установленное. Трудное название — заведите слот со своим словом.

</details>

<details>
<summary><b>Можно ли включить Wi-Fi, Bluetooth или режим полёта голосом?</b></summary>

Система не даёт приложениям переключать их напрямую. Команда откроет экран или панель — останется одно касание.

</details>

<details>
<summary><b>Ассистент слушает всё время? А батарея?</b></summary>

Зависит от режима. **«Активация по кнопке»** — самый экономный: микрофон выключен, пока вы не нажмёте кнопку. **«На домашнем экране»** (по умолчанию) — микрофон включён только на домашнем экране — циферблате, рабочем столе или другом экране, который система считает домашним, а распознавание запускается, только когда звук громче порога. режим **«Во всех приложениях»** — микрофон включён всегда, расход самый большой.

</details>

<details>
<summary><b>В углу экрана горит зелёная точка</b></summary>

Так система показывает, что микрофон используется. Это нормально, пока ассистент слушает. В режиме «Активация по кнопке» точка появляется только после нажатия кнопки.

</details>

<details>
<summary><b>Что значат цвета иконки микрофона?</b></summary>

«Цвет при запуске» — микрофон включается. «Цвет при записи» — микрофон включён и слушает. От речи цвет не меняется: слышит ли ассистент ваш голос, видно на странице «Настройки микрофона» (при речи «Ждёт» сменяется на «Распознаёт»). Цвета, размер и положение настраиваются на странице «Иконка микрофона»; иконку можно и скрыть.

</details>

### Установка и устройства

<details>
<summary><b>На часах Huawei APK не ставится</b></summary>

Это ограничение прошивки часов: системный установщик пакетов мешает установке. Ставьте по беспроводной отладке — см. [Часы Huawei](#часы-huawei). Один раз: дальше приложение обновляется само.

При установке с телефона через Assist Voice (окно <kbd>ADB</kbd>) установщик отключается и включается обратно автоматически. Если ставите APK сами через приложение для ADB, **перед установкой отключите установщик, а после — обязательно включите обратно** (команды для консоли ADB):

```
pm disable-user --user 0 com.android.packageinstaller
pm install /путь/к/файлу.apk
pm enable --user 0 com.android.packageinstaller
```

</details>

<details>
<summary><b>Кнопка ADB пишет «Нужна отладка по Wi-Fi» или не находит устройство</b></summary>

Включите в «Для разработчиков» отладку по сети и подключитесь к Wi-Fi. Если устройство подключается по коду сопряжения — при первом подключении откройте на нём экран с кодом, без него оно не подключится. Если пункта отладки по сети нет — включите её один раз с компьютера: `adb tcpip 5555`. Раздела «Для разработчиков» нет — коснитесь 7 раз номера версии или сборки в «О телефоне» / «О часах». На Xiaomi ещё нужен пункт «Отладка по USB (настройки безопасности)». Подробнее — [Совместимость](#-совместимость).

</details>

<details>
<summary><b>Переключатель службы серый, пишет «Ограниченная настройка»</b></summary>

Это защита системы для приложений, установленных из файла. См. [Ограниченные настройки](#ограниченные-настройки) или нажмите кнопку ADB.

</details>

<details>
<summary><b>Работает ли на других часах (Xiaomi, Amazfit и т. д.)?</b></summary>

Если на часах полноценный Android или Wear OS и на них можно установить APK — должен работать. Проверено на Huawei Watch 3 / 3 Pro, Watch 4 / 4 Pro, OnePlus Watch и Samsung Galaxy Watch. Не узнаёт циферблат — включите режим «Во всех приложениях» и напишите модель. Часы на собственных системах (не Android) не поддерживаются.

</details>

<details>
<summary><b>Работает ли на iPhone?</b></summary>

Нет, только Android.

</details>

### VIP и интеграции

<details>
<summary><b>VIP правда бесплатный?</b></summary>

Да: подписка на канал и код боту. Поддержать разработку деньгами можно по желанию — VIP от этого не зависит.

</details>

<details>
<summary><b>GigaChat: «ключ недействителен», «квота закончилась», «занят»</b></summary>

«Ключ недействителен» — вставлен не «Ключ авторизации» или не целиком; получите новый в кабинете Сбера. «Квота закончилась» — бесплатная квота аккаунта исчерпана; попробуйте другую модель кнопкой «Модель». «GigaChat занят» — бесплатный тариф отвечает на один вопрос за раз, дождитесь ответа на предыдущий.

</details>

<details>
<summary><b>GigaChat не услышал начало вопроса</b></summary>

Начинайте говорить, когда открылось окно и появилось «Слушаю…». Сказанное вместе со словом-активатором в вопрос не попадает — так обрывки команды не уходят в вопрос.

</details>

<details>
<summary><b>StarLine не пускает при входе</b></summary>

Ключи (AppId и Secret) должны быть созданы в том же аккаунте, под которым вы входите, и вставлены без пробелов. Запросил код из СМС или с картинки — введите на той же странице. Одноразовые пароли из приложения StarLine не поддерживаются: нужен обычный пароль аккаунта.

</details>

<details>
<summary><b>StarLine отвечает «принята», а не «выполнена»</b></summary>

Машина не успела подтвердить: слабая связь у сигнализации, подземный паркинг. Команда, скорее всего, выполнится чуть позже — проверьте справкой «состояние машины».

</details>

<details>
<summary><b>Hikvision: камеры нет в списке</b></summary>

В списке только каналы с видеосигналом: камера без сигнала или пустой канал регистратора не показываются. Проверьте камеру в приложении Hik-Connect.

</details>

<details>
<summary><b>Голос озвучки не скачивается</b></summary>

Загрузка идёт только по Wi-Fi или мобильной сети. На часах выключите Bluetooth на время скачивания, чтобы часы пошли в сеть напрямую. Нужно около 63 МБ свободного места.

</details>

## 🔒 Конфиденциальность и безопасность

- 🎤 **Голос команд не покидает устройство.** Команды распознаются на часах или телефоне; звук не записывается и не отправляется. Исключение — диктовка вопроса GigaChat через распознавание Google, если оно выбрано: тогда звук вопроса обрабатывает Google по своим правилам (галочка «Распознавание голоса только офлайн» это отключает).
- 🚫 **Нет рекламы и аналитики.** Статистика использования не собирается.
- 🌐 **В сеть — только то, что вы сами подключили:** команды Умного дома Яндекса, Hik-Connect и StarLine уходят прямо в эти сервисы. Вопрос GigaChat (только текст, без звука) уходит прямо в Сбер под вашим ключом и только после слова вопроса.
- 🔑 **Ключи и пароли хранятся только на устройстве** в зашифрованном виде; при передаче с телефона на часы шифруются в браузере телефона и расшифровываются только на часах.
- 👥 **Контакты** читаются только для звонков и никуда не передаются. Исключение — перенос настроек по коду: туда входят имена и номера из ваших слотов-звонков.
- 📄 **Лог** уходит разработчику только по кнопке «Отправить лог»; речи, контактов и ключей в нём нет.
- 👁 **Служба специальных возможностей** не читает содержимое экрана — только название открытого приложения.
